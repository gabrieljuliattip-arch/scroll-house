# Scroll House — Portfólio

Sites com animação 3D guiada pelo scroll, feitos com **HTML, CSS e JavaScript** (Three.js + GSAP).

| Projeto | Pasta | Descrição |
|---|---|---|
| RAIO Energy | [`energetico/`](energetico) | Energético fictício: lata 3D que gira e troca de sabor conforme o scroll · [ver site](https://scroll-house-eight.vercel.app) |
| Navalha Barbearia | [`barbearia/`](barbearia) | Barbearia fictícia: poste de barbeiro 3D que acompanha o scroll · [ver site](https://scroll-house-barbearia.vercel.app) |
| Dikebras (proposta) | [`dikebras/`](dikebras) | Modelo de site para barbearia real: tesoura e navalha, sinuca e copão em 3D, agenda online · [ver site](https://scroll-house-dikebras.vercel.app) |
| Espelhado | [`estetica/`](estetica) | Estética automotiva fictícia: peça pintada que é polida no scroll, água escorrendo na vitrificação |

Cada pasta é um site independente. Veja o README de cada uma para rodar localmente e publicar na Vercel.
